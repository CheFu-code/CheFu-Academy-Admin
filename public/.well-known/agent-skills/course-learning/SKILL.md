# Course Learning

Use this skill when helping a learner find, create, continue, or practice a CheFu Academy course.

## Key URLs

- Course search: `/courses/search?query={topic}`
- Create a course: `/courses/create-course`
- My courses: `/courses/my-courses`
- Practice hub: `/courses/practice`

## Workflow

1. Search courses when the user names an existing topic.
2. Use create course when the user wants a custom AI-generated course.
3. Guide learners through the next unlocked chapter in order.
4. Recommend quizzes, flashcards, or Q&A practice after finishing a chapter.

## Notes

Course progress is sequential. For incomplete courses, only the next required chapter should be opened.
