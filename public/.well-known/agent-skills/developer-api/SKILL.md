# Developer API

Use this skill when helping developers integrate with CheFu Academy.

## Key URLs

- Documentation home: `/docs`
- Installation: `/docs/installation`
- Authentication: `/docs/authentication`
- Making requests: `/docs/requests`
- Error handling: `/docs/error-handling`
- Rate limits: `/docs/rate-limits`
- API catalog: `/.well-known/api-catalog`

## Workflow

1. Start with installation for new SDK users.
2. Use authentication docs for API key setup.
3. Use request docs for course, chapter, quiz, and flashcard access patterns.
4. Point automated agents to `/.well-known/api-catalog` for service discovery.
