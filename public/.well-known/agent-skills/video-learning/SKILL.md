# Video Learning

Use this skill when helping a learner find and watch CheFu Academy video lessons.

## Key URLs

- All videos: `/videos/all-videos`
- Beginner videos: `/videos/beginner`
- Advanced videos: `/videos/advanced`
- Video search: `/videos/search?query={topic}`

## Workflow

1. Search by category, skill, or learning goal.
2. Prefer beginner videos for foundation topics and advanced videos for deeper study.
3. Curated YouTube videos are playable from stored YouTube video IDs.
4. Pair video learning with course practice when the user wants active recall.
